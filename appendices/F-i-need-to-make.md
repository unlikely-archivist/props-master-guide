# Appendix F: "I Need to Make…" Finder

Look up the prop, then follow the links. Each row lists the usual **routes** (buy, rent, alter, build), the **chapters and projects** to read, and the **safety notes** that apply. Routes are starting points. Always run the needs-and-means check first ([ch. 22](../guide/4-fabrication-core/22-the-build-method.md)) and decide whether to pull, borrow, rent, buy or build ([ch. 11](../guide/2-admin/11-buy-source-or-build.md)). Rows draw on the chapters they link to; suggested routes not found in a source are the guide's own **[Suggestion]**.
