# Props Master Guide

Working reference guides for props artisans and props masters. Each guide is a synthesis of source material, reorganised for use in the shop.

## Guides

| Guide | Source | Covers |
|---|---|---|
| [Fake Food Master Guide](fake-food/MASTER-GUIDE.md) | Harrison & Honesty, *The Fake Food Cookbook: Props You Can't Eat for Theatre, Film, and TV* (Routledge, 2018) | Real-vs-fake decisions, safety, a playbook for each material (salt dough, candle wax, XPS foam, Smooth-On molding and casting, expanding foam, Encapso K, coatings, glazes), an effect finder, recipe cards for all 41 dishes, tiered supply list, troubleshooting, show reference |
