# Instructions for Claude

- Never write slurs, even when quoting, flagging, or repeating a source. Describe them instead (e.g., "an ethnic slur on p. 165").
- The master guide lives on the default branch. Integrate each new source into the existing chapters and appendices: give it a citation code, cite page numbers, and add it to the README citation key, Appendix C, Appendix D and the glossary. Don't write standalone guides.
- When sources disagree, state each position with its citation (e.g., "FF says X (FF 38); Hart says the opposite (H 267)"). Don't pick a winner or add a recommendation that resolves the disagreement.
